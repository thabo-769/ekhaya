# Ekhaya Takeaways homepage

Responsive React + TypeScript + Vite + Tailwind CSS homepage inspired by the supplied design reference.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Before publishing

This is a frontend preview. Replace the menu and prices in `src/App.tsx` with approved information; verify branch addresses, phone numbers, opening hours, WhatsApp/email, promotions and social links; add the approved Ekhaya logo and genuine restaurant photography. The contact form and order panel do not send data. Connect a confirmed ordering channel and form service before launch. Current food photos are remotely hosted Unsplash images.
